## 使用的查询

```sql
-- 每个模型点最后一条非0数据时间
SELECT pointId,
       MAX(CASE WHEN value NOT REGEXP '^0(\\.0*)?$' THEN created_at END) AS last_nonzero
FROM device_data_save
WHERE pointId IN ('BGT-N1', ... 共27个 ...)
GROUP BY pointId;

-- 最近7天逐日 非0/总行数
SELECT DATE(created_at) d,
       SUM(CASE WHEN value NOT REGEXP '^0(\\.0*)?$' THEN 1 ELSE 0 END) AS nonzero,
       COUNT(*) AS total
FROM device_data_save
WHERE pointId IN ('BGT-N1', ... 共27个 ...)
  AND created_at >= NOW() - INTERVAL 7 DAY
GROUP BY DATE(created_at) ORDER BY d;
```

> 注：`value` 为 varchar，判断 0 使用正则 `'^0(\.0*)?$'`（匹配 `0`、`0.0` 等写法）。
