# 环境数据时序预测 — final 实验报告 v2

> **项目**: 鸡舍环境多变量时序预测（27维环境特征 → 未来6小时）
> **模型**: NLinear / XLinear / DLinear（固定种子，各训练3次，均值±标准差）
> **粒度**: 5分钟聚合 | **输入窗口**: 24小时(288点) | **预测窗口**: 6小时(72点)

---

## 1. 项目概述

利用过去 24 小时（288 个 5 分钟点）的 27 维环境传感器数据，预测未来 6 小时（72 个 5 分钟点）。

- 数据源：表1(2026-02~03冬) + 表2(2026-07夏) + 表3(2026-08夏末，长段 seg105 全部划入训练集，因为一共504点，分不了训练验证和测试集)
- 模型：轻量线性模型 NLinear / XLinear / DLinear
- 方法：**固定随机种子**（seed=0,1,2，每模型3次），报告**均值±标准差**
- 指标口径：**标准化空间（z-score）**为主，物理尺度为辅

## 2. 数据清洗与修正

### 2.1 BGT 黑球温度 10倍倍率修正

表1中 `BGT-N1/BGT-N/BGT-S` 在 **2026-02-10 16:23 ~ 2026-02-13 15:27** 出现 85~222°C 异常值。

诊断（10倍倍率错误）：
- 同时段普通温度 TEM 正常（5~22°C，2月冬季合理）
- BGT/TEM 比值恒为 10（中位数 9.78~10.17，接近10占比 96~99.5%）
- 三列同步异常、同步恢复，为系统性问题

**修正**：该时段 BGT ÷ 10。修正后 BGT 恢复至 0~22°C。

### 2.2 问题列剔除

| 列 | 原因 |
|---|---|
| HUM-S_湿度南 | 表2全0（传感器未采集） |
| TEM-S_温度南 | 表2全0（传感器未采集） |
| PM25-S_PM25南 | 与 PM10-S 100%重复 |

保留 **27 个有效特征**。

### 2.3 全0行彻底处理（v2 关键改进）

**问题**：v1 清洗以原始30列判定全0，剔除3列后遗留 **378 行 27列全0**（2026-02-11 ~ 2026-07-22，散布11个段）。

**v2 处理**（严格满足"样本不覆盖全0行"）：

1. **全0判定改为基于最终27列**
2. **1分钟粒度 27列全0行直接删除**（不插值、不进入任何样本）：表1删2006行、表2删372行、表3删15行
3. NaN 行直接删除：表1删14行、表3删1行
4. 5分钟聚合（均值），聚合后残余全0/NaN 删除
5. **分段规则改为"时间缺口 > 5min 即切断"** → 全0行删除处自然成为 segment 边界
6. 滑窗严格在 segment 内部生成，**任何样本的 X/Y 窗口都不跨越全0行位置**

结果：**清洗后 0 全0行、0 NaN** ✅

## 4. 模型、随机种子与物理约束

### 4.1 随机种子

```python
for seed in SEEDS:
    set_seed(seed)          # ① 先设置种子 (Python/NumPy/PyTorch)
    model = CLS[name](...)  # ② 再创建模型
    r = run_once(model, ...)
```
每个 seed 的模型初始化、数据加载、训练完全可复现。

### 4.2 模型定义

| 模型 | 核心思想 | 参数量 |
|---|---|---|
| NLinear | 减去最后时刻再线性映射 + 加回 | 20.8K |
| XLinear | 减去整段均值再线性映射 + 加回 | 20.8K |
| DLinear | 移动平均分解趋势/季节分别映射 | 41.6K |

### 4.3 物理约束（按特征，非统一截断）

| 特征 | 约束 |
|---|---|
| 湿度 HUM* | [0, 100] |
| CO2 / PM / LIG / NH3 / WIN / TSP | [0, +∞) |
| 温度 TEM* | [-20, 60] °C |
| 黑球温度 BGT* | [-20, 80] °C |

- 训练 loss：`MSE + λ·mean(relu(LO-pred_raw) + relu(pred_raw-HI))`，λ=1.0
- 评估：逆变换后按特征 clamp

### 4.4 超参数

| 项 | 值 |
|---|---|
| 优化器 / LR / wd | Adam / 1e-3 / 1e-5 |
| Batch / Epochs / Patience | 512 / 60 / 10 |
| 调度器 | CosineAnnealingLR |
| 梯度裁剪 | 1.0 |
| **随机种子** | **seed=0,1,2（全固定）** |

## 5. 实验结果（3次重复 均值±标准差）

### 5.1 三模型 vs 基线（测试集 1194 样本，标准化空间）

| 模型 | MAE | MSE | RMSE | **R2** | Corr |
|---|---|---|---|---|---|
| NLinear | 0.2493±0.0009 | 0.1871±0.0003 | 0.4325±0.0004 | 0.7845±0.0004 | 0.8885 |
| XLinear | **0.2477±0.0008** | 0.1876±0.0003 | 0.4331±0.0004 | 0.7839±0.0004 | 0.8873 |
| DLinear | 0.2584±0.0006 | **0.1862±0.0002** | 0.4316±0.0002 | 0.7854±0.0002 | 0.8888 |

**关键发现**：

1. **XLinear MAE 最低（0.2477）**，DLinear R²/MSE/Corr 最高（0.7854/0.1862/0.8888），各模型各有优势
2. **seg4全部划入训练后效果大幅提升**：R² 从 0.737 → 0.785（+0.048），因为8月不再作为域外测试，且模型学到了夏末数据分布
3. 三模型训练稳定：MAE 标准差 ≤0.0009，R² 标准差 ≤0.0004

### 5.2 分月对比（标准化 MAE）

| 月份 | 样本数 | NLinear | XLinear | DLinear |
|---|---|---|---|---|
| 2月（冬） | 612 | 0.2368 | 0.2337 | **0.2257** |
| 3月（冬） | 327 | 0.2303 | **0.2291** | 0.2628 |
| 7月（夏） | 255 | **0.3036** | 0.3051 | 0.3315 |

> 注：8月数据已全部划入训练集（seg105 全train），不再出现在测试集。8月样本用于训练后，2/3/7月指标也同步受益（模型分布更完整）。

- 冬季（2-3月）误差低于夏季（7月）
- DLinear 2月最优，XLinear/NLinear 3月最优，NLinear 7月最优

## 7. 结论与建议

### 7.1 结论

1. **推荐 XLinear 或 NLinear 部署**：MAE 0.248~0.249、R² 0.784~0.785，差距 <1%；参数量仅 20.8K
3. **全0行处理彻底**：清洗后 0 全0行，样本不覆盖任何无效数据
4. **可复现**：种子先设再建模型，3次训练 R² 标准差 ≤0.0004

### 7.2 部署建议

- 模型：`models/XLinear_s0.pt`（或 NLinear_s0.pt）
- 预处理：`scaler.pkl` 标准化 → 模型 → 逆变换 → 按特征 clamp 物理范围
- 输入：最近 288 个 5 分钟点 → 输出：未来 72 点（6小时）
